# Privacy Policy / 隱私權政策

Last updated: 2026-07-13

---

## 🔒 繁體中文 (Traditional Chinese)

「PDF 圖片工具箱」(PDF Image Toolkit) 致力於保護您的個人隱私。本政策說明我們如何處理您的文件與數據。

### 1. 數據收集與處理
* **完全本地端處理**：本軟體的所有功能（包含 PDF 合併、PDF 壓縮、PDF 拆分、PDF 轉圖片等）均完全在您的本地電腦執行。
* **無遠端伺服器上傳**：本軟體不設有任何遠端伺服器，亦不包含任何數據上傳模組。您的文件（圖片、PDF等）絕不會被上傳至任何網路位置。
* **無個人資料收集**：本軟體不收集、不儲存、亦不分享您的任何個人識別資料（例如姓名、電子郵件、IP 地址或設備識別資訊）。

### 2. 網路連線說明
* 本軟體為完全離線運行的應用程式，在任何情況下皆不需要且不會要求網路連線權限。

### 3. 隱私權政策變更
* 我們可能會不時更新本隱私權政策。任何變更都將直接反映在此頁面上。

## 🔒 English

"PDF Image Toolkit" is committed to protecting your personal privacy. This privacy policy explains how we handle your documents and data.

### 1. Data Collection and Processing
* **100% Local Processing**: All features of this application (including PDF Merge, PDF Compress, PDF Split, PDF to Image) are executed entirely on your local machine.
* **No Remote Server Upload**: This application does not use any remote servers and contains no telemetry or data upload modules. Your files (images, PDFs, etc.) will never be uploaded to any network location.
* **No Personal Data Collection**: This application does not collect, store, or share any personal identification information (such as name, email address, IP address, or device identifiers).

### 2. Network Connectivity
* This application is a fully offline utility. It does not require, request, or use any network access permissions.

### 3. Changes to This Policy
* We may update our Privacy Policy from time to time. Any changes will be posted directly on this page.
